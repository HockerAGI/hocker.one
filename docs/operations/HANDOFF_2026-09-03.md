## 8. Free-runtime decision

Railway is not required for Hocker One primary operation.

Current external research:
- Oracle Cloud Always Free provides persistent VM resources for the life of the account within quotas; this is the strongest fit for running the unchanged nova.agi Docker image.
- Render Free is explicitly not for production and spins down on idle.
- Cloud Run has a free tier but requires a billing account.
- Cloudflare Workers has growing Node compatibility but is a different execution model from a persistent Fastify process.
- Deno Deploy has a free tier but would require runtime adaptation.

Therefore the next runtime action is: prepare a provider-neutral OCI deployment path without changing application architecture, then perform human account provisioning only when needed. No paid plan is required for the target design, but Oracle signup commonly requires a payment card for identity verification and Always Free quota/capacity is not an SLA.
